# 测试验证报告说明

报告文件为 `NPU与传感器校准SoC测试验证报告.md`，同名 Word 用于编辑和提交，PDF 用于检查页面显示效果。报告包含 7 章、5 幅插图、5 张表格和 3 个可编辑公式。

报告分别介绍 NPU RTL 功能与接口验证、TFLM 模型联合仿真、推理调用周期以及 MicroBlaze FPGA SoC 的资源和时序。板级部分给出模型加载、内存读写、数值比较、实际传感器采样与 OLED 显示的测试方法。结果统计分别对应原始 RTL 用例、PicoRV32 仿真模型和 FPGA 实现配置。

插图保存在 `test_figures/`，每幅包含 SVG 和 PNG。流程图使用圆角矩形和彩色圆角箭头，结果图使用测试记录中的整数差异、调用周期和器件资源数量。`test_results.json` 保存提取后的数值和来源文件摘要；`test_diagram_audit.json` 保存流程图几何检查结果；`test_quality_audit.json` 保存文档检查结果；页面检查图片保存在 `test_proofs/`。

在本目录重新导出并检查报告：

```sh
python3 build_test_report.py --converter /path/to/md_report_to_docx.py
python3 audit_test_report.py
```

从工程记录重新提取测试数据：

```sh
python3 collect_test_results.py \
  --fpga-project /path/to/VU3P_sensor_v2 \
  --software-project /path/to/sensor_sw_v2
```

导出脚本沿用项目指定的 Word 转换程序，可通过 `--converter` 指定其位置。正文采用五号宋体，标题、目录和图表题使用黑体，表格内容水平及垂直居中，公式保存为 Word 可编辑数学对象。重新导出时同时生成 Word 和 PDF，并刷新目录及页码。

Word 导出的 PDF 共 14 页。文档结构检查覆盖 32 个目录跳转、5 幅图片、5 张表格和 3 个独立公式；数值检查逐项核对 RTL 周期、模型整数输出和 FPGA 资源统计。全部页面已检查字体、分页、图题位置及图内文字，流程图的节点、箭头和文字通过几何检查。
