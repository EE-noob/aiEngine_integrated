# 详细设计报告核查说明

检查对象包括 Markdown、Word、PDF、八幅插图、图源及本目录的说明文件。`quality_audit.json` 保存实际检查结果、文件校验值及页面信息，`diagram_audit.json` 保存自绘图的几何检查结果。

## 技术内容

报告围绕传感器校准 SoC 的当前设计展开。SoC 部分说明 MicroBlaze V、本地 BRAM、两主设备输入与十六从设备输出的 AXI 互连、NPU 和单个共享存储控制器，并说明 125 MHz 总线时钟、复位控制和外设连接。相关参数核对 Block Design 与硬件封装文件。

NPU 部分说明矩阵地址计算、零点和量化参数、int32 偏置处理、寄存器字段、输入缓存、权重装入、部分和保存、两类数据流、读仲裁及写回完成条件。输入缓存、处理单元和高精度重量化的描述核对相应 RTL，实现参数使用传感器 SoC 的集成配置。

软件部分说明 TFLM 的模型解释与张量管理、Init/Prepare/Eval 操作、全连接算子适配、NMSIS-NN 兼容接口和 NPU 驱动调用。传感器特征构造、残差恢复及 OLED 输出核对模型运行程序、主程序和显示函数。电压、电流和湿度分别使用 18、12 和 7 个输入特征。

FPGA 部署部分核对 Vivado 平台导出、Vitis 平台更新、TFLM 静态库构建、CMake 配置、模型数据声明、链接脚本、COE 生成和 ELF 合并脚本。程序、本地初始化数据、模型常量和 arena 分别说明其存储位置及初始化方式。

验证章节说明存储访问、单算子、连续任务、完整模型精度和执行时间的检查方法。理论算力注明阵列规模与频率，模型误差比较注明输入、量化和物理单位，测试方法与实际测量结果分别表述。

## 语言与格式

语言检查覆盖 Markdown、Word 与 PDF 提取文字、全部自绘 SVG、绘图程序及说明文件。量化术语按技术含义使用，其他限制词按具体上下文核查。正文以技术对象、执行条件和具体操作组织陈述。

Word 使用指定转换脚本的页面及正文格式，封面、章节、目录和图表题统一为黑体。检查程序核对字体样式、直接文字属性及 PDF 实际字体。表格单元格水平与垂直居中，公式以可编辑数学对象保存，目录条目与 PDF 跳转目标逐项核对。

## 插图与页面

图 2 使用指定原始 PNG，文件内容、像素尺寸和比例分别检查。其余七幅图的节点、文字和箭头由同一绘图程序生成，几何检查覆盖箭头端点、节点范围、文字范围和路径间距。图源与渲染图一同保存在插图压缩文件中。

`proofs/` 保存 PDF 的逐页渲染图及四页组合预览。页面检查覆盖封面、目录、章节标题、图题、表格、数学公式和末页，检查结果与报告正文分开保存。
