# 项目设计报告说明

报告正文由三个并列主题组成：NPU 设计、SoC 设计与 FPGA 部署、软件栈设计。各部分介绍设计目标、总体方案、技术特点及应用成果，TFLM 背景与模型校准处理在软件栈部分说明。

主稿为 `简明NPU与SoC设计技术报告.md`，同名 Word 和 PDF 用于编辑与提交。正文包含三幅架构图，图 1 采用指定 NPU 原图，SoC 图和软件体系图采用圆角矩形及彩色箭头。

在本目录执行：

```sh
python3 build_report.py
python3 audit_report.py
```

构建程序调用指定科技报告转换脚本，并复用相邻 `详细设计报告` 目录中的字体及绘图支持。封面、章节、目录和图题统一为黑体，正文使用五号宋体及 Times New Roman。Word 和 PDF 的语言、结构、字体、图题及目录由检查程序核对，结果保存在 `quality_audit.json`，页面预览保存在 `proofs/`。

`draw_figures.py` 保存自绘图的编辑定义，生成 SVG、PNG 和几何检查记录。NPU 图直接使用 `/media/3/0-课题/TFLM加速器/架构设计-AXI.png`，SoC 图采用已经核对当前硬件结构的总体架构。`插图与图源.zip` 保存报告插图和对应绘图程序。

当前文档共八页，正文为三个并列章节，包含三幅架构图和十三个目录条目。语言、标题字体、目录跳转及图题检查通过，全部页面已完成视觉检查。自绘图通过节点、文字和箭头的几何检查，NPU 插图与指定原图的文件内容一致。
